# Hi, I'm T. J. Chartrand

**Turning wrenches before code. Still taking things apart to understand them.**

I've always had trouble leaving things alone: machines, software, systems, ideas. If something works, I want to know why. If it doesn't, I want to know where it broke.

I build desktop software and automation, mostly around Windows, Linux, and local-first tools. A lot of it starts with noticing the friction between having a thought and actually doing something with it.

## Currently building: Stickity

A notes and actions app built around a simple idea: software should help carry some of the weight of remembering what comes next, not become another thing you have to manage.
